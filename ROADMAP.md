# Public Site Roadmap

1. **P0 — Decisions:** apply the accepted static-first Astro architecture; accept package-manager, detailed routing, deployment, testing, and browser-support ADRs.
2. **P1 — Foundation:** scaffold, CI, environment validation, tokens, typography, locale router, API client, state primitives.
3. **P2 — Shell:** language gateway, header, navigation, footer, theme, skip link, metadata.
4. **P3 — Core pages:** bilingual home, about, CV/resume, contact, search.
5. **P4 — Collections:** research, projects, writing, publications, teaching, creative work and detail pages.
6. **P5 — Media and interaction:** responsive media, diagrams, timelines, graph views, reduced-motion behavior.
7. **P6 — Quality:** browser, accessibility, visual-regression, performance, failure-state, and SEO gates.
8. **P7 — Cutover:** preview deployment, content reconciliation, redirect plan, release evidence, rollback drill.

No phase is complete because a page merely renders. Its contract, state coverage, tests, and evidence must pass.
