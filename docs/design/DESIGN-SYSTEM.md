# Public Design System

The implementation must derive tokens and component requirements from the shared design specification and verified asset register under `../../../../Docs/04-design/`. Use semantic tokens for color, spacing, typography, radius, elevation, motion, and layout; components must not encode unexplained one-off values.

The visual identity may use the verified logo, portal imagery, scientific/graph motifs, teal and gold accents, and bilingual typography. Decorative imagery must never reduce text contrast or determine reading order. Themes must remain legible without depending on background art.
