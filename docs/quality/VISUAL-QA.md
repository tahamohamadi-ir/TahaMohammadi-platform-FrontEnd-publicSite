# Visual QA

Capture gateway, shell, home, one collection, one detail, contact, search, empty, unavailable, and error states. Cover Persian and English, light and dark, 360, 768, 1280, and 1920 CSS-pixel widths. Include long text and missing optional media.

Compare against the approved design specification and registered reference assets. A screenshot resembling a concept is not acceptance when typography, contrast, direction, spacing, or state behavior is wrong.
